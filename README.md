# Artifact - 1
##Photo-Display

The artifact I selected is my enhanced OpenGL/GLFW graphics program, originally created during CS 330 course as a foundational rendering assignment. It began as a simple scene with basic meshes but I chose it for my ePortfolio because it demonstrates how I apply algorithms, data structures, and transformation logic to build a functional 3D environment. The artifact showcases structured use of vectors, matrices, and transformation pipelines, along with organized mesh drawing routines that rely on reusable functions and parameterized data. Throughout the enhancement process, I improved the artifact by adding new objects, textures, and behaviors such as the flower meshes while also refining shader loading and rendering logic. These improvements highlight my ability to analyze existing code, identify weaknesses, and apply algorithmic thinking to extend functionality in a clean, maintainable way.
Enhancing the artifact helped me get closer to meeting the course outcomes I planned to address in Module One, especially those related to implementing algorithms, managing data structures, debugging, and improving software design. I strengthened my understanding of how transformation matrices, texture coordinates, and mesh data interact, and I gained hands on experience resolving real development challenges such as missing libraries, incorrect paths, and shader loading errors. This process taught me how to troubleshoot systematically, how to break problems into smaller steps, and how to modify code without breaking existing functionality. While I have not met the outcomes I originally targeted, I now see opportunities to expand my skills further such as improving modularity and experimenting with more advanced rendering techniques.
To enhance realism further, the next phase of development will introduce a flower arrangement that reflects a version of the bouquet in the original scene. This improvement will involve generating stem and petal meshes, applying detailed textures stored and retrieved through SQL, and refining lighting to capture the warm, organic atmosphere of the reference. By expanding the scene with natural elements and more nuanced materials, the project will evolve from basic geometric reconstruction into a richer, more lifelike visual experience supported by thoughtful coding and design.
