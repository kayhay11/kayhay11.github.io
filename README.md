# kayhay11.github.io
To enhance realism further, the next phase of development will introduce a flower arrangement that reflects a version of the bouquet in the original scene. This improvement will involve generating stem and petal meshes, applying detailed textures stored and retrieved through SQL, and refining lighting to capture the warm, organic atmosphere of the reference. By expanding the scene with natural elements and more nuanced materials, the project will evolve from basic geometric reconstruction into a richer, more lifelike visual experience supported by thoughtful coding and design.
